DTS Enabler

Restores DTS and Dolby TrueHD/MLP audio on rooted LG TVs whose firmware removed it — verified on webOS 25 (C5), including DTS in .mkv, .mp4, .ts and .m2ts. Decodes native discrete 5.1 (no stereo downmix). Enable / disable / uninstall from the app, plus a self-test and play-by-ear. No stock firmware file is modified in place: the overrides are bind-mounts reverted by Disable/Uninstall or a reboot, and the one persistent write — the GStreamer plugin registry — is reverted by regenerating a clean stock registry.

It also tells you when you don't need it: 2024 sets (C4/G4/M4/T4) kept native DTS and are reported as needing nothing, and a set whose decoder is present but switched off is reported as such rather than as unsupported. Applies its mechanism only to TVs whose stock plugins match a verified set and whose model was actually tested; a byte-identical match on an untested model, or anything else, requires the explicit experimental opt-in.

Requires the Homebrew Channel with root. Not endorsed by LG.
