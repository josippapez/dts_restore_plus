Actions

Enable stages the payload and installs the boot hook for the detected profile (applied now, no reboot). Disable removes the boot hook and unmounts the overrides; no stock file is modified in place, and the one persistent write — the GStreamer plugin registry — is reverted by regenerating a clean stock one. A bind that is busy is detached lazily and clears fully on reboot. Uninstall also removes all on-device state.

The boot script installed on this TV is older than the one this app version ships, so a reboot would still apply the older compatibility gate. Press Enable to refresh it. Nothing is rewritten until you do.

Make-up gain & dynamic range

The custom DTS and TrueHD decoders play quieter than LG's native codecs, and neither applies any dynamic range compression by default (unlike LG's own Dolby/DTS decoders). Tune a per-codec make-up gain (dB), a DRC preset (Off/Light/Medium/Night) and a dialogue (center-channel) boost here — no SSH or rebuild needed. Values are written on-device and take effect on the next playback (decoder init), not the current one.

A/B compare

Renders the bundled clip twice on this TV — A with DRC off and 0 dB gain/dialogue, B with your saved settings — then lets you play each, so you hear the difference on identical content. It drives the decoder directly, so your saved settings are never touched (the hashes below prove it). The bundled samples are DTS, so this exercises the DTS path only, not TrueHD.

Test the patch

Run self-test decodes a bundled DTS sample in each container (mp4, ts, m2ts) through the TV's media pipeline and reports PASS/FAIL — an objective check that the patch works, no speakers needed. Play plays a sample so you can confirm by ear.
